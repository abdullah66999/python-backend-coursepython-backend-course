# Python Backend Projects

Десять проектов из учебного курса. Каждый проект можно открыть отдельно.

## Порядок

1. `01_budget_app` — функции, ввод, ошибки и pytest.
2. `02_task_manager` — SQLite, CLI и тесты.
3. `03_notes_api` — FastAPI, SQLAlchemy и HTTP-тесты.
4. `04_production_service` — FastAPI, Redis, очередь, Docker Compose и healthcheck.
5. `05_csv_analytics` — CSV, Decimal, группировка и отчёты.
6. `06_url_shortener` — FastAPI, валидация URL, redirect и HTTP-тесты.
7. `07_webhook_receiver` — HMAC, идемпотентность и безопасный webhook.
8. `08_async_dashboard` — asyncio, httpx, timeout и частичные ошибки.
9. `09_search_cli` — pathlib, regex, JSON и CLI.
10. `10_job_queue` — asyncio.Queue, worker и graceful shutdown.
11. `11_telegram_planner` — aiogram 3, FSM, inline-кнопки, SQLite и Docker.

Для каждого проекта сначала прочитайте README внутри папки, создайте виртуальное окружение и запускайте команды по порядку. Не переходите к следующему проекту, пока не можете объяснить текущий.
